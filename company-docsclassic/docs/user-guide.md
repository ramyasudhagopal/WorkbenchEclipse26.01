# User Guide

## Overview of the User Guide

Welcome to Workbench Eclipse. This guide explains how to get started, configure the application, and use its main features.

## Getting Started

1. Install and launch Workbench Eclipse.
2. Choose or create a workspace when prompted.
3. Review the available projects and tools in the main workbench.
4. Open a project to begin working.

## Workspaces and Projects

A workspace is the location where your projects, settings, and metadata are stored. To manage projects:

- Use **File > New** to create a project.
- Use **File > Import** to add an existing project.
- Use **File > Open Project** to open a project in the current workspace.
- Use **File > Close Project** to close a project without deleting its files.

## Editing Files

Open a file from the project explorer to edit it. Use the editor toolbar or keyboard shortcuts to save, undo, redo, find text, and format content. Unsaved changes are marked in the editor tab; save your work regularly.

## Running and Debugging

1. Select the project or file you want to run.
2. Choose **Run** from the toolbar or main menu.
3. To investigate an issue, start a **Debug** session.
4. Use breakpoints, the variables view, and the console to inspect program behavior.

## Preferences

Open **Window > Preferences** to customize the editor, appearance, workspace behavior, and other tools. Select **Apply** to keep changes or **Restore Defaults** to reset a section.

## Troubleshooting

- Restart the application if the interface becomes unresponsive.
- Refresh the project before rebuilding it.
- Check the console and error views for diagnostic messages.
- Confirm that the correct workspace and project are selected.
- If a problem persists, record the error message and steps to reproduce it.

## Getting Help

Use the built-in help menu and search documentation for feature-specific guidance. When reporting an issue, include the application version, operating system, workspace details, and relevant error messages.
