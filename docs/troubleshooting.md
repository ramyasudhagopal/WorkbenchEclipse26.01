# Troubleshooting

Find solutions to common problems with the note-taking application.

## Cannot Sign In

If you cannot sign in, check your username and password. Make sure that you have an active internet connection.

## Application Is Not Responding

If the application is not responding, refresh the application and try again. If the problem continues, contact your system administrator.

## Common Questions

<details>
<summary>Why can't I create a notebook?</summary>

Make sure you are signed in and have permission to create a notebook. If the problem continues, contact your system administrator.

</details>

<details open>
<summary>Before You Begin</summary>

Make sure you have:

- An active user account
- Internet access
- A supported web browser

</details>

## Still Need Help?

Contact your system administrator if you cannot resolve the problem.
